#### Sub-phase 0.4 — Git + GitHub (Days 9-10)

**Learn:** `git init`, `add`, `commit`, `push`, `.gitignore`, creating a repo on GitHub, writing a basic `README.md`, branches (`git checkout -b`), merging.

**Where exactly:**

- [GitHub's own "Git Handbook"](https://guides.github.com/introduction/git-handbook/) (free, short)
- [Learn Git Branching](https://learngitbranching.js.org/) — interactive, free, do the first 4-5 levels only

**Assignment 0.4 — "Publish Your Expense Tracker"**

*Problem statement:*

1. Initialize a git repo in your expense tracker project
2. Create a proper `.gitignore` (exclude `venv/`, `__pycache__/`, `.env`)
3. Write a `README.md` explaining what the project does and how to run it
4. Push it to a new public GitHub repository
5. Create a new branch called `feature/monthly-summary`, add a method that groups expenses by month, commit it, then merge that branch back into `main`

*What "done" looks like:* A real, public GitHub repo with a clean commit history (at least 4-5 meaningful commits, not one giant "initial commit"), a working README, and evidence you used a branch and merged it — this is literally how you'll work on every future project.
